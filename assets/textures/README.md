# Recording floor texture

`motphys-ground.png` is the original Motphys-logo floor texture served by the
UniLab demo site:

- Texture: https://unilabsim.github.io/examples/assets/unilab_motrix_onnx_tasks/assets/robots/common/motphys-ground.png
- Material configuration: https://unilabsim.github.io/examples/assets/unilab_motrix_onnx_tasks/assets/robots/common/flat_ground.xml

The texture is used unchanged for offline video rendering. Material texture
repeat `(0.4, 0.4)` and tint `(0.7, 0.7, 0.7, 1)` match that configuration.
Motphys branding remains part of the original texture. The rendering report
records its SHA-256 hash. This asset does not change the live simulation's
robot model or physics parameters.
