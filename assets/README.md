# 素材目录

- `images/`：首屏封面、架构图、结果图和演示图片。
- `textures/`：离线录制视频使用的地板贴图，来源见该目录的 README。
- `videos/`：推荐 H.264 编码的 MP4；建议提供 WebP / JPG 封面。
- `logos/`：单位与合作机构标志，推荐 SVG 或透明 PNG。
- `favicon.svg`：FM 字母融合图标，带深色底用于浏览器标签页。
- `logos/flashmimic.svg`：导航栏与页脚使用的 FM 标记，透明背景。

将文件路径填入根目录的 `site-content.js`。路径留空时使用现有占位布局。
